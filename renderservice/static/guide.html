Как подготовить проект

К рендерам

Сервер рендерит проект так, как он сохранён: движок, разрешение, сэмплы и кадры берутся из файла. Поэтому всё, что нужно сцене, должно лежать рядом с .blend, а настройки быть выставлены до загрузки.

Проверь настройки рендера

  • Движок, разрешение, сэмплы, диапазон кадров (Frame Start и End) выставлены так, как нужен итог.
  • Для анимации выбери вывод последовательностью картинок (PNG или JPEG), а не видео. Тогда после сбоя или отмены рендер можно продолжить, и превью готовых кадров появляются по ходу работы. Видео из кадров можно собрать после скачивания.
  • Папка вывода в проекте не важна: сервер сам сохраняет результат в renders.
  • Сохрани файл (Ctrl+S) после всех изменений.

Положи текстуры рядом с проектом

Лучше всего работает такая схема: у проекта своя папка, а файлы лежат внутри неё и в Blender указаны относительными путями (//textures/wood.jpg). Абсолютные пути вроде /home/user/... или C:\... на сервере не существуют.

Способ А: выгрузить всё рядом автоматически

  1. Создай папку проекта, например my_scene, и сохрани туда файл (File → Save As).
  2. File → External Data → Pack Resources. Blender упакует все внешние файлы внутрь .blend.
  3. File → External Data → Unpack Resources…, в списке выбери Use Files in Current Directory (create when necessary). Blender создаст рядом с .blend папку textures (для звуков, шрифтов и т. п. создаются свои папки) и пропишет в проекте относительные пути.
  4. File → External Data → Make Paths Relative, чтобы убедиться, что все остальные пути тоже относительные.
  5. Сохрани файл ещё раз.

Способ Б: текстуры уже лежат на диске

  1. Скопируй нужные текстуры в папку проекта (например, в textures).
  2. File → External Data → Find Missing Files и укажи эту папку: Blender перепривяжет файлы по именам.
  3. File → External Data → Make Paths Relative.
  4. File → External Data → Report Missing Files. В сообщении не должно остаться пропавших файлов.
  5. Сохрани файл.
Если проект небольшой, можно просто упаковать всё в один файл: File → External Data → Pack Resources, сохранить и загрузить один .blend без архива. Файл станет больше, а кэши симуляций, видео и связанные блендеры внутрь не упаковываются, для них нужен архив.

Собери zip-архив

В архиве должна лежать папка проекта целиком, с сохранённым расположением файлов:

my_scene/
  scene.blend
  textures/
    wood.jpg
    metal_normal.png
  blendcache_scene/

Linux и macOS (из папки, в которой лежит my_scene):

zip -r my_scene.zip my_scene -x "*.blend1" "*/renders/*"

Windows: правый клик по папке → «Отправить» → «Сжатая ZIP-папка». macOS: правый клик → «Сжать».

  • Не перемещай .blend и текстуры друг относительно друга после настройки путей.
  • В архиве может быть несколько .blend: сервер предложит выбрать нужный.
  • Резервные копии (.blend1) и старые рендеры в архив класть не нужно.

Что ещё должно лежать рядом

  • Связанные библиотеки (Link/Append из других .blend).
  • Кэши Alembic, USD, OBJ-последовательности, видео и HDRI.
  • Симуляции (дым, жидкость, ткань): запеки заранее (Bake) с включённым Disk Cache и положи в архив папку blendcache_имяфайла. Иначе сервер будет считать симуляцию заново.
  • Пути на файлы выше папки проекта (//../shared/tex.png) в архив не попадут, перенеси такие файлы внутрь.

Перенеси аддоны и настройки Blender

Если в сцене нужны аддоны, один раз перенеси их на сервер: на главной странице раздел «Настройки Blender». Сервер сам включит их при каждом рендере.

  1. Найди файл userpref.blend в папке настроек своего Blender (подставь свою версию вместо 4.5): 
    Linux:   ~/.config/blender/4.5/config/userpref.blend
Windows: %APPDATA%\Blender Foundation\Blender\4.5\config\userpref.blend
macOS:   ~/Library/Application Support/Blender/4.5/config/userpref.blend
  2. Загрузи этот файл кнопкой «Загрузить настройки». Можно загрузить и zip со всей папкой 4.5: тогда вместе с настройками уедут и аддоны из scripts/addons и extensions.
  3. Сервер прочитает список включённых аддонов. Встроенные в Blender найдутся сами, расширения с extensions.blender.org он скачает сам (нужен Blender 4.2 или новее).
  4. Всё, что сервер не нашёл, окажется в списке «Нужно добавить». Загрузи такие аддоны кнопкой «Добавить аддон»: это .zip или один файл .py. Имя аддона в архиве должно совпадать с тем, что записано в списке.
Тема, раскладка клавиш и прочие настройки интерфейса на рендер не влияют, их сервер игнорирует. Версии Blender до 4.2 не знают про расширения: они используют только обычные аддоны.

Чего сервер не делает

Скрипты проекта не запускаются (автозапуск Python отключён из соображений безопасности): Python-выражения в драйверах и скриптовые ноды не сработают. Если сцене они нужны, запеки результат до загрузки.
  • Аддоны работают только те, что перенесены в разделе «Настройки Blender» (см. выше). Если аддон не включился, в задаче появится предупреждение.
  • Рендерится только активная сцена файла.
  • Файлы, которые записывают ноды File Output в композиторе, сохраняются по путям проекта, а не в renders.

После загрузки

  • Дождись статуса «готов» и проверь строку с параметрами: движок, разрешение, сэмплы, кадры.
  • Если написано «Не найдено файлов», вернись к пункту 2: исправь пути и загрузи проект заново. Запускать рендер без этих файлов можно, но на изображении они будут отсутствовать.
  • Версию Blender сервер определяет по файлу проекта. Если такой нет в папке, он её скачает сам, либо её можно скачать вручную в разделе «Версии Blender» на главной странице.
  • Исходные файлы проекта хранятся на сервере несколько дней, результаты месяц. Если ты поправил проект, загрузи его заново.
