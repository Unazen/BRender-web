# Прототип удалённого рендера Blender (этап 0)

Консольный прототип без веб-интерфейса. Его задача: проверить на твоём железе главные риски до написания сервера.

## Файлы

- `blendver.py` читает версию Blender из заголовка .blend (обычный, gzip и zstd; старый и новый формат заголовка).
- `blender_wrapper.py` запускается внутри Blender: включает OptiX/CUDA, направляет вывод в `renders/`, пишет прогресс в JSON, умеет preflight.
- `render_cli.py` запускает Blender, парсит лог, показывает кадр, сэмплы и оставшееся время.

## Подготовка на Arch

```bash
sudo pacman -S nvidia-utils xorg-server-xvfb
pip install --user zstandard
```

Скачай нужную версию Blender (tar.xz для Linux) с blender.org и распакуй, например в `~/blender/4.5.12/`.

## Запуск

Проверка проекта без рендера (движок, разрешение, сэмплы, кадры, пропавшие текстуры):

```bash
python render_cli.py ~/projects/scene/scene.blend --blender ~/blender/4.5.12/blender --preflight
```

Рендер одного кадра на OptiX:

```bash
python render_cli.py ~/projects/scene/scene.blend --blender ~/blender/4.5.12/blender --mode still
```

Рендер анимации, результат в `scene/renders/`:

```bash
python render_cli.py ~/projects/scene/scene.blend --blender ~/blender/4.5.12/blender --mode animation
```

Флаги:

- `--device OPTIX|CUDA|CPU` устройство Cycles (по умолчанию OPTIX, при отсутствии GPU откат на CPU).
- `--xvfb` запуск через виртуальный экран, нужен если EEVEE не стартует без дисплея.
- `--out ПУТЬ` папка результата (по умолчанию `renders/` рядом с проектом).
- `--frame N` номер кадра для режима `still` (по умолчанию текущий кадр проекта).
- `--frames НАЧАЛО:КОНЕЦ` диапазон кадров для режима `animation` вместо диапазона проекта, например `--frames 1:3` для быстрого теста.

Рядом с `renders/` появятся `render.log` (полный лог Blender) и `progress.json`.

## Что проверить и сообщить мне

1. Preflight выдаёт корректные данные и список пропавших файлов.
2. В начале лога строка `[wrapper] устройство:` показывает твою RTX 3060 через OptiX.
3. Одиночный кадр Cycles рендерится, строка статуса показывает сэмплы и время.
4. Анимацию на 3-5 кадров: считаются кадры и оставшееся время, файлы попадают в `renders/`.
5. Проект на EEVEE: стартует ли без `--xvfb`, а если нет, работает ли с ним.
6. Старый проект на Blender 3.x с соответствующей версией: запускается ли на 3060.

## Известные ограничения прототипа

- Аддоны включаются после загрузки .blend, поэтому аддоны с собственными типами нод пока не подойдут. Это решим на этапе 4.
- Рендерится только активная сцена файла.
- Файлы из Compositor (File Output) пишутся по путям проекта, а не в `renders/`.
- Докачка после сбоя пока опирается на отключённую перезапись кадров, её нужно проверить на деле.
- Если версия Blender не совпадает с версией проекта, прототип только сообщает версию проекта. Автоскачивание версий будет на этапе 3.
